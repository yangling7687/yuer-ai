====================
一、类型定位与核心结构
====================

「国学育儿型」是以古今穿越为表现方式，将现代家庭教育冲突与古代贤者、典故、人物智慧相结合的育儿剧情短视频。

本类型不是历史知识讲解，也不是简单的古装情景剧，更不是让古人站出来长篇说教。

它的核心是：

现代育儿冲突
→ 孩子情绪受挫或陷入困惑
→ 孩子穿越进入古代情境
→ 遇到古代贤者或典故人物
→ 古代故事折射现代育儿问题
→ 贤者给出具体、可执行的方法
→ 孩子带着方法回到现代
→ 父母改变回应方式
→ 亲子关系完成温暖和解。

核心落点必须是：

“父母应该如何回应孩子，孩子可以如何处理问题，家庭可以如何把道理变成行动。”

本类型适合的主题包括：

- 孩子犯错后如何面对；
- 孩子考试失利；
- 孩子被同伴误解；
- 孩子不敢表达；
- 孩子害怕失败；
- 孩子被父母比较；
- 孩子不愿意尝试；
- 孩子情绪失控；
- 孩子被批评后产生委屈；
- 孩子不愿意承认错误；
- 孩子面对输赢；
- 孩子缺乏自信；
- 孩子不懂得坚持；
- 父母过度催促或过度否定；
- 父母只关注结果，忽略过程；
- 家长如何给孩子安全感、边界感和成长空间。

不适合强行套用本类型的内容包括：

- 纯粹的历史知识介绍；
- 只有古人名言，没有现代家庭冲突；
- 只有父母说教，没有孩子情绪；
- 只有穿越特效，没有育儿方法；
- 只有拥抱和解，没有前面的矛盾铺垫；
- 让古人替父母直接训斥孩子；
- 将孩子塑造成完美、早熟、没有负面情绪的人；
- 通过羞辱、比较和恐吓制造亲子和解。

====================
三、平台精选内容四大特征
====================

四大特征是整条视频的内容质量目标，不是装饰性口号，也不要求每一段平均使用相同表现方式。

必须将四大特征落实到：

- 选题；
- 现代冲突；
- 穿越方式；
- 古代典故；
- 贤者台词；
- 育儿方法；
- 镜头表达；
- 情绪变化；
- 现代和解；
- 结尾收口。

【1. 获得感】

获得感是指：

通过趣味、专业且容易理解的知识、经验或见解，让家长看完后真正获得可以应用的方法。

在国学育儿型中，获得感必须完成两次转化：

第一层：

古代典故或贤者智慧，准确对应现代育儿痛点。

第二层：

将古代道理转化成今天父母和孩子都能执行的具体行动。

每条内容必须尽量回答：

- 孩子遇到了什么问题；
- 父母原本哪里回应不当；
- 古代典故对应什么人生道理；
- 贤者具体指出了什么关键；
- 父母回家后可以怎么做；
- 孩子下次可以怎么说、怎么做；
- 这个方法如何迁移到其他家庭场景。

禁止只输出：

- 要懂事；
- 要坚强；
- 要努力；
- 要孝顺；
- 要听话；
- 要控制情绪；
- 要尊重父母；
- 要做更好的自己。

必须将抽象道理转化为可执行方法，例如：

- 先接住情绪，再讨论对错；
- 孩子犯错时，先问“发生了什么”，再问“下次怎么办”；
- 孩子失败后，先区分结果和努力过程；
- 父母批评前，先让孩子完整表达；
- 孩子害怕尝试时，把目标拆成第一小步；
- 孩子被误解时，先帮助孩子澄清事实；
- 孩子情绪激动时，先暂停争辩，再恢复沟通；
- 与其催促孩子立刻做到，不如先陪孩子练习一次；
- 与其比较别人家的孩子，不如看见孩子自己的进步；
- 道歉不能只要求孩子说出口，还要帮助孩子完成补救行动。

每个古代典故必须对应一个现代育儿方法。

典故不能只作为装饰，也不能脱离原意强行解释。

【2. 惊喜感】

惊喜感是指：

通过古今时空碰撞、人物隐喻、典故折射和现代反差，让观众产生眼前一亮的感觉。

惊喜感不能只依靠：

- 突然出现古装人物；
- 大量烟雾和闪光特效；
- 古人突然说金句；
- 现代家长被古人训斥；
- 孩子突然长篇顿悟；
- 结尾强行拥抱。

真正的惊喜感可以来自：

- 孩子发现古代官员竟然像自己的父母；
- 古代典故中的人物困境与孩子经历形成镜像；
- 贤者没有直接批评父母，而是通过故事让父母意识到问题；
- 古人用一个生活细节解释现代育儿难题；
- 孩子回到现代后没有立刻反驳父母，而是换了一种更成熟但符合年龄的表达；
- 父母从“只看结果”转向“先理解过程”；
- 现代场景中的一个道具与古代典故形成匹配；
- 同一演员分饰现代家长和古代冲突人物，形成心理隐喻；
- 古代一句话在现代被转化为一个具体动作；
- 结尾不是孩子被动接受安慰，而是父母主动改变回应方式。

六段整体中至少安排两处明显的惊喜点。

惊喜必须满足：

- 服务于育儿主题；
- 符合人物年龄；
- 现实情绪真实；
- 不依赖复杂特效；
- 不让古人像现代心理咨询师一样长篇分析；
- 不把孩子写成成人化小大人；
- 不通过羞辱父母制造爽点。

【3. 表达力】

表达力是指：

在有限时长内，让观众清楚看懂现代冲突、孩子情绪、穿越原因、古代隐喻、贤者方法和现代变化。

全片必须清楚传达：

1. 现代家庭发生了什么；
2. 孩子为什么委屈、害怕或失望；
3. 父母哪一句话或哪一个动作造成了冲突；
4. 孩子为什么进入古境；
5. 古代场景如何对应现代问题；
6. 贤者通过什么故事或行为进行点化；
7. 孩子学到了什么具体方法；
8. 回到现代后，父母如何改变；
9. 亲子关系如何自然缓和。

画面、动作、台词和音乐必须分工明确：

- 画面交代冲突；
- 动作展示情绪；
- 台词推动关系变化；
- 古代道具承接典故；
- BGM区分现代压抑、古境宁静和回归温暖；
- 角色表情体现情绪转折；
- 片6完成情感和解；
- 片7完成育儿原则总结。

禁止让所有信息都由旁白讲出。

禁止使用：

- 连续大段旁白解释；
- 多人同时说话；
- 古人长篇训话；
- 孩子长篇哲理演讲；
- 无意义的跑动、烟雾、空镜和特效；
- 只展示哭泣，却不交代哭泣原因；
- 只展示拥抱，却不交代父母改变了什么。

【4. 感染力】

感染力是指：

让家长在孩子的委屈、父母的反思和亲子关系的修复中产生真实共鸣。

感染力来自：

- 孩子害怕被责备；
- 孩子努力后仍然失败；
- 孩子想解释却没有被听见；
- 父母本意是着急，却用错了表达方式；
- 古代贤者让父母看见孩子的真实感受；
- 孩子回到现代后仍然有一点犹豫；
- 父母没有立刻说教，而是先接住孩子；
- 和解不是“孩子必须道歉”，而是双方重新理解；
- 结尾让家长感觉“我家孩子也值得被这样回应”。

禁止强行煽情：

- 禁止孩子长时间嚎哭；
- 禁止父母夸张跪地忏悔；
- 禁止大人突然痛哭失声；
- 禁止用疾病、意外或极端伤害制造泪点；
- 禁止让孩子承担修复全部关系的责任；
- 禁止用“别人家的孩子”羞辱主角；
- 禁止将父母塑造成纯粹反派。

情绪应当自然递进：

现代压抑
→ 孩子委屈或失望
→ 穿越后的孤独与迷茫
→ 古境中的安静观察
→ 贤者点化后的理解
→ 回到现代后的犹豫
→ 父母回应方式改变
→ 亲子关系温和修复。

====================
四、视频时长与六段剧情分配
====================

本类型为16:9横屏真人实拍育儿剧情短视频。

总时长必须达到或超过60秒。

默认结构为：

- 片1：约10秒，现代冲突起拍；
- 片2：约10秒，孩子情绪升级并进入穿越；
- 片3：约10秒，古代冲突人物出现，与现代家长形成隐喻；
- 片4：约10秒，古代贤者讲述典故或展示行为；
- 片5：约10秒，孩子理解方法并回到现代；
- 片6：约10秒，现代亲子和解与情绪收口；
- 如平台或剪辑方案需要片7，片7约5秒，用于育儿原则、旁白或字幕收口。

如果采用片7，则总时长约65秒；
如果不采用片7，则片1至片6必须分别达到约10秒，总时长不得低于60秒。

【建议结构】

片1：现代冲突建立

- 前2秒内交代家庭矛盾；
- 使用明确的生活动作起拍；
- 让观众知道孩子因为什么被否定、催促、比较或误解；
- 不使用危险破坏动作。

片2：孩子情绪升级与穿越

- 孩子表达委屈、害怕或失望；
- 情绪可以达到高点，但必须符合年龄；
- 孩子通过离开房间、靠近旧物、触碰书卷、闭眼或情绪停顿进入古境；
- 不安排跳楼、冲出马路、翻窗、狂奔等危险动作。

片3：古代冲突隐喻

- 古代冲突制造者由现代起冲突家长的同一名演员饰演；
- 古代人物与孩子形成心理镜像；
- 不直接说“我就是你爸爸/妈妈”；
- 通过脸部、语气、动作和服装形成观众可理解的隐喻；
- 典故冲突必须与现代育儿问题对应。

片4：贤者点化

- 贤者通过典故、生活故事、道具或简短对话给出方法；
- 道理必须简短；
- 必须转化为具体的现代育儿行动；
- 不得成为脱离剧情的国学讲座。

片5：回到现代

- 孩子带着方法回到原来的现代场景；
- 家庭空间、人物服装和光线必须与前片保持一致；
- 孩子不必立刻完美改变；
- 可以先用新的表达方式尝试沟通；
- 父母开始意识到自己的回应方式需要调整。

片6：亲子和解

- 父母采取具体的改变动作；
- 例如蹲下倾听、放下手中物品、停止催促、拥抱、牵手、陪孩子重新尝试；
- 孩子表达真实感受；
- 结尾以拥抱、牵手、击掌、陪伴或共同完成任务收口；
- 不使用强行煽情和夸张哭喊。

片7：育儿原则收口

如果采用片7：

- 画面必须与现代主场景和人物状态保持一致；
- 旁白或字幕总结一个共同育儿原则；
- 不重复前面全部台词；
- 不使用空泛口号；
- 5秒内完成；
- 片7必须与脚本、分镜和Seedance提示词完全对应。

====================
五、现代冲突与多角色对冲规则
====================

现代冲突段落可以使用多角色，但每个角色必须有明确功能。

可使用：

- 主攻家长；
- 爆发或委屈的孩子；
- 缓冲家长；
- 保护长辈；
- 兄弟姐妹或同伴。

建议单段最多出现4名角色。

主要说话角色不超过3人。

角色功能：

- 主攻家长：体现催促、比较、误解或错误回应；
- 孩子：表达委屈、反抗、犹豫或尝试沟通；
- 缓冲家长：阻止冲突继续升级或提供短暂观察；
- 长辈：从生活经验角度提供保护、陪伴或情绪缓冲；
- 同伴：只在确有必要时参与，不抢夺亲子主线。

禁止多人同时说话。

禁止所有角色连续大喊。

禁止把家长写成恶意伤害孩子的纯反派。

【强动作起拍规则】

片1可以使用具有视觉冲击力的生活动作起拍，例如：

- 家长快速合上作业本；
- 孩子把笔放下；
- 家长将手机从孩子面前拿开；
- 书本滑落到茶几上；
- 孩子把书包放到地上；
- 家长猛地站起；
- 孩子突然抬头、后退或转身。

但必须遵守：

- 禁止摔手机；
- 禁止砸碎物品；
- 禁止推搡、扇打、拉扯；
- 禁止踢门、撞门、撞墙；
- 禁止将危险破坏动作作为爽点；
- 禁止让儿童模仿危险行为；
- 物理动作只用于建立节奏，不用于制造暴力。

【高潮前置规则】

情绪冲突应尽早出现，但不得强行在前2秒完成所有爆发。

片2可以在前2—4秒出现孩子明显情绪升级，例如：

- 孩子声音发抖地说“我已经很努力了”；
- 孩子转身离开；
- 孩子抱住书包；
- 孩子低头擦泪；
- 孩子停在门边没有继续争吵；
- 孩子看见旧书、古物或家中摆件后产生穿越触发。

情绪高潮必须服务于穿越和后续点化，不得成为单纯吵架表演。

====================
六、穿越与古今隐喻规则
====================

【穿越触发】

穿越触发必须具有剧情因果，不得凭空出现。

可使用：

- 古籍被翻开；
- 旧书页上的墨迹晕开；
- 孩子触碰家中的古物；
- 茶杯、毛笔、砚台、扇子或书卷与现代道具匹配；
- 孩子闭眼深呼吸后，环境音改变；
- 家长的一句话与古代典故产生声音或画面衔接；
- 现代物品的动作匹配古代物品。

禁止：

- 突然爆炸式穿越；
- 复杂空间撕裂；
- 强烈闪白刺眼；
- 人物瞬间消失；
- 身体变形；
- 违反物理规律的飞行；
